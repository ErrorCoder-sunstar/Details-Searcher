# 🌍 Sunstar Wikipedia Search Tool

A simple command-line application built with Python that allows users to search Wikipedia and retrieve a concise summary of any topic. The application uses the `wikipedia` Python library to fetch information directly from Wikipedia.

This project is ideal for beginners learning how to work with external Python libraries and APIs.

---

## 📌 Features

- 🔍 Search any topic on Wikipedia.
- 📖 Display a concise summary (2 sentences).
- ⚡ Fast and lightweight command-line application.
- 🌐 Retrieves live information from Wikipedia.

---

## 🛠️ Technologies Used

- Python 3
- Wikipedia Python Library

## ▶️ Installation

### Clone the repository

```bash
git clone https://github.com/your-username/Sunstar-Wikipedia-Search.git
```

### Navigate to the project folder

```bash
cd Sunstar-Wikipedia-Search
```

### Install the required package

```bash
pip install wikipedia
```

or

```bash
pip install -r requirements.txt
```

---

## ▶️ How to Run

```bash
python main.py
```

## ⚠️ Current Limitations

- Displays only the first **2 sentences** of a Wikipedia article.
- Requires an active internet connection.
- Does not handle ambiguous search terms.
- No exception handling for missing pages or network errors.
